Under the hood

How a Flask request works

  1. 01 The browser sends a request, e.g. GET /quote.
  2. 02 Flask matches the URL to a route in app.py.
  3. 03 Python runs the logic and queries the SQL database.
  4. 04 Jinja fills an HTML template with the results.
  5. 05 The finished page is sent back to the browser.
