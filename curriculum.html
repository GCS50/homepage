Curriculum

Every lecture of the course: the topics, each assignment in its problem set explained, and the skills it builds.

Week 0

Scratch

Computational thinking, how computers represent information (binary, ASCII, Unicode, RGB), and the building blocks of every program: functions, conditionals, loops and variables.

  • Scratch – an original game, story or animation built with Scratch's visual blocks.

Computational thinkingAbstractionBinary

Week 1

C

From blocks to text: syntax, types, operators, loops, and compiling source code into machine code with make.

  • Hello, It's Me – asks for the user's name and greets them.
  • Mario – prints a pyramid of bricks using nested loops and validated input.
  • Cash / Credit – computes change with the fewest coins, or validates card numbers with Luhn's algorithm.

C syntaxCompilationLoopsInput validation

Week 2

Arrays

What happens when code is compiled, debugging, how arrays and strings are stored in memory, command-line arguments, and an introduction to cryptography.

  • Scrabble – decides which of two players' words scores more points.
  • Readability – estimates the reading grade level of a text with the Coleman-Liau index.
  • Caesar / Substitution – encrypts text by rotating or substituting letters using a key from the command line.

ArraysStringsDebuggingCryptography

Week 3

Algorithms

Linear and binary search, bubble, selection and merge sort, running time in asymptotic notation (O, Ω, Θ), and recursion.

  • Sort – works out which of three programs uses selection, bubble or merge sort by measuring their running times.
  • Plurality – runs a simple plurality election.
  • Runoff / Tideman – ranked-choice elections, decided by instant runoff or by building a graph of candidates that must avoid cycles.

Big OSortingRecursionStructs

Week 4

Memory

Pointers, segmentation faults, dynamic allocation with malloc and free, the stack and the heap, buffer overflows, and reading and writing files.

  • Volume – scales the volume of a WAV audio file.
  • Filter – applies grayscale, reflection, blur and either sepia or edge detection to BMP images, pixel by pixel.
  • Recover – recovers deleted JPEG photos from a forensic image of a memory card.

Pointersmalloc / freeFile I/OValgrind

Week 5

Data Structures

Abstract data types: stacks and queues, linked lists, binary search trees, hash tables and tries, and the trade-offs between time and memory.

  • Inheritance – simulates how blood types are inherited across generations.
  • Speller – a spell checker that loads a dictionary into a hash table, tuned for speed.

Linked listsHash tablesTriesOptimization

Week 6

Python

Rewriting familiar programs in a high-level language: functions, conditionals, loops, lists, dictionaries, modules and packages.

  • Hello, Mario, Cash / Credit, Readability – earlier C programs re-implemented in Python.
  • DNA – identifies a person from a DNA sequence by counting short tandem repeats.

PythonDictionariesCSVLibraries

Week 7

SQL

Relational databases: tables, types, constraints and indexes, querying with SELECT, JOIN and subqueries, plus race conditions and SQL injection attacks.

  • Songs – answers questions about the 100 most-streamed songs on Spotify in 2018.
  • Movies – queries an IMDb database of movies, people and ratings.
  • Fiftyville – finds out who stole the CS50 Duck, where the thief fled and who helped, using nothing but SQL queries.

SQLSQLiteJOINsSQL injection

Lecture

Artificial Intelligence

How AI works under the hood: prompt engineering, decision trees and minimax, machine learning, neural networks, and large language models built on the transformer architecture.

Machine learningNeural networksLLMs

Week 8

HTML, CSS, JavaScript

How the internet and HTTP work (TCP/IP, DNS, GET and POST), and the structure, style and behavior of web pages with HTML, CSS, JavaScript and frameworks like Bootstrap.

  • Trivia – a quiz page that gives instant feedback through JavaScript event listeners.
  • Homepage – this website.

HTMLCSSJavaScriptBootstrap

Week 9

Flask

Server-side web applications in Python: routes and decorators, requests and responses, Jinja templates, sessions and cookies, with a SQL database behind it all.

  • Birthdays – a web app that keeps track of friends' birthdays in a SQLite database.
  • Finance – a web app with user accounts where users check real stock prices and “buy” and “sell” shares with virtual cash.
